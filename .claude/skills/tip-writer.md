# 팁 작성 보조 스킬

## 목적

개발자가 Claude Code 사용 중 발견한 노하우를 빠르게 포스트잇 카드 형식으로 정리해준다.
직접 타이핑 부담을 줄이고, 일관된 카드 품질을 유지한다.

## 동작 흐름

1. 사용자가 경험한 노하우를 자유롭게 설명하도록 유도
2. 아래 3가지를 대화로 추출:
   - **제목** (20자 이내, 핵심 한 문장)
   - **본문** (200자 이내, 구체적인 방법·예시 포함)
   - **태그** (아래 중 하나 선택)
3. 완성된 카드 초안을 보여주고 수정 여부 확인
4. 확정 시 `app.js` POST 포맷으로 출력

## 태그 선택지

- `프롬프트작성` — 효과적인 프롬프트 작성법
- `디버깅` — 오류 해결·디버깅 관련
- `코드리뷰` — 코드 리뷰 요청·개선 관련
- `워크플로우` — 개발 흐름·작업 순서 관련
- `기타` — 위 분류에 해당하지 않는 팁

## 출력 포맷

```json
{
  "title": "제목 (20자 이내)",
  "body": "본문 (200자 이내)",
  "tag": "태그"
}
```

## 보안 주의사항

팁 작성 시 아래 내용이 포함되지 않도록 안내:
- 고객 개인정보·계좌정보
- 내부 시스템 URL·API 키·인증 정보
- 미공개 비즈니스 로직

## 예시 대화

```
사용자: /tip-write
Claude: 어떤 노하우를 공유하고 싶으신가요? 자유롭게 설명해주세요.
사용자: 클로드코드로 디버깅할 때 에러 메시지만 붙여넣기하면 원인을 잘 못 찾더라고요.
        스택 트레이스 전체를 넣어줘야 훨씬 잘 찾아줘요.
Claude: 좋은 팁이네요! 아래처럼 카드를 만들어봤어요.

        제목: 디버깅 시 스택 트레이스 전체를 입력하세요
        본문: 에러 메시지만 붙여넣으면 원인 파악이 어렵습니다.
              스택 트레이스 전체를 포함하면 Claude Code가
              정확한 원인과 수정 위치를 훨씬 잘 찾아줍니다.
        태그: 디버깅

        이대로 제출할까요, 수정할 부분이 있나요?
```
