# 팁 요약·분류 스킬

## 목적

축적된 팁 데이터를 빠르게 정리하여 팀 채널에 게시할 주간 요약 초안을 생성한다.

## 입력 방법

Google Sheets에서 전체 행을 복사(Ctrl+A → Ctrl+C)하여 붙여넣기.
또는 CSV 형식으로 제공.

예시:
```
timestamp,title,body,tag,likes
2026-06-09 10:00,디버깅 시 스택 트레이스 전체 입력,에러 메시지만 넣으면...,디버깅,7
2026-06-10 14:30,CLAUDE.md에 자주 쓰는 명령 정리,반복 설명을 줄이려면...,워크플로우,5
```

## 동작 흐름

1. 입력 데이터 파싱 (timestamp·title·body·tag·likes)
2. 태그별 팁 수 집계 및 분류
3. likes 기준 상위 3개 베스트 팁 선정
4. 중복 의심 팁 탐지 (제목·본문 유사도 기준)
5. 팀 채널 게시용 마크다운 초안 생성

## 출력 포맷

```markdown
## 🗒️ 이번 주 Claude Code 꿀팁 요약 (YYYY-MM-DD 기준)

**총 XX개 팁 등록됨**

### 카테고리별 현황
- 프롬프트작성: N개
- 디버깅: N개
- 코드리뷰: N개
- 워크플로우: N개
- 기타: N개

### 👍 이번 주 베스트 팁 3선

1. **[제목]** `#태그` 👍N
   > 본문 요약

2. **[제목]** `#태그` 👍N
   > 본문 요약

3. **[제목]** `#태그` 👍N
   > 본문 요약

### ⚠️ 중복 의심 팁
(유사한 내용의 팁이 있을 경우 목록 표시)
```

## 보안 주의사항

- 팁 데이터를 외부 AI 서비스에 붙여넣기 전, 민감 정보 포함 여부 확인
- 고객 데이터·API 키가 팁 본문에 포함된 경우 해당 행 제외 후 실행
