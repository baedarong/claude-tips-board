# 게시판 운영 전반 스킬

## 목적

게시판 운영자(또는 AI Crew 담당자)가 단일 명령으로 필요한 운영 작업을 선택·실행할 수 있도록 한다.

## 진입 메뉴

`/board-ops` 실행 시 아래 메뉴를 표시:

```
📋 게시판 운영 메뉴
━━━━━━━━━━━━━━━━━━
1. 팁 작성 보조      → 새 팁 카드 구조화
2. 팁 요약·분류      → 주간 요약 초안 생성
3. 중복 탐지         → 유사 팁 목록 추출
4. 전체 운영 리포트  → 2·3번 통합 실행
━━━━━━━━━━━━━━━━━━
번호를 입력하세요.
```

## 각 메뉴 동작

### 1. 팁 작성 보조
`tip-writer` 스킬과 동일하게 동작.
자유 설명 → 제목·본문·태그 추출 → 카드 초안 확인 → POST 포맷 출력.

### 2. 팁 요약·분류
`tip-summarizer` 스킬과 동일하게 동작.
Sheets 데이터 붙여넣기 → 카테고리 집계 → 베스트 3 선정 → 마크다운 초안 출력.

### 3. 중복 탐지

입력된 팁 목록에서 아래 기준으로 유사 팁을 탐지:
- 제목이 70% 이상 유사한 경우
- 본문 핵심 키워드가 3개 이상 겹치는 경우

출력 포맷:
```
🔍 중복 의심 팁 목록
─────────────────────
[그룹 1]
  - (A) "디버깅 시 스택 트레이스 전체 입력" (2026-06-09, 👍7)
  - (B) "에러 디버깅할 때 전체 로그 붙여넣기" (2026-06-11, 👍2)
  → 권장 조치: A 유지, B 삭제 검토

[그룹 2]
  ...
```

### 4. 전체 운영 리포트

2번(요약·분류) + 3번(중복 탐지)를 순서대로 실행하여 하나의 운영 리포트로 통합 출력.
매주 월요일 운영 루틴으로 활용 가능.

## 보안 주의사항

- 3번·4번 실행 시 외부 AI 서비스에 붙여넣는 데이터에 민감 정보 미포함 여부 확인
- 중복으로 판단된 팁 삭제 전 운영자가 직접 Sheets에서 내용 검토 후 결정
